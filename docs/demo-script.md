# Demo script

Four scripted prompts, each highlighting one aspect of the agent. Rehearse at least twice end-to-end before showing the demo.

**Reset before each demo:** reload the MCA Content Builder canvas on an empty email, confirm `TargetLanguage = en_US` unless the prompt says otherwise. Have Data Cloud → Data Explorer open in another tab in case anyone asks to see the DMO rows.

## Prompt 1 — End-to-end image selection (anchor demo)

**Setup:** Canvas locale `en_US`.

**Prompt:** *"Create a promo email section with a headline, paragraph, and image for our summer sale."*

**What happens:**
1. Agent calls `CreateOrRefineSectionWithContent` → generates headline + paragraph + image component slot.
2. Agent calls `SelectMarketingImage` with:
   - `keyMessage` = "summer sale promo" (or similar)
   - `locale` = `en_US`
   - `campaign` = `summer_sale` (inferred)
3. Retriever returns an asset tagged `locale_en_US` + `campaign_summer_sale`.
4. Canvas renders generated copy + the Contentful image inline.

**What to say to the room:** "Everything you see — the copy, the image, the layout — was selected or generated by the agent in one pass. The image came from Contentful, routed through a Data Cloud catalog that the agent queries with the same intent signals it uses to write the copy."

## Prompt 2 — Campaign swap

**Setup:** Same canvas, same locale.

**Prompt:** *"Now make the same section but for our holiday campaign."*

**What happens:**
1. Agent calls `CreateOrRefineSectionWithContent` with `userInput` mentioning "holiday."
2. Agent calls `SelectMarketingImage` with `campaign` = `holiday` (inferred).
3. Different image appears — one tagged `campaign_holiday`.

**What to say:** "The agent picked up the new campaign from the request and swapped the image accordingly. No manual asset browsing."

## Prompt 3 — Visual style swap

**Setup:** Same canvas and campaign.

**Prompt:** *"Make it more editorial — less product-shot, more lifestyle."*

**What happens:**
1. Agent refines the section with the same campaign but tone cues now pushing `visualStyle` = `editorial`.
2. Different image, same campaign bucket but different style tag.

**What to say:** "This is the semantic layer earning its keep — the agent didn't just filter on a tag, it understood that 'editorial' and 'lifestyle' are related style qualities and picked an asset that matches."

## Prompt 4 — Locale swap

**Setup:** Switch the canvas locale to `en_GB`.

**Prompt:** *"Create a summer sale section like we had before."*

**What happens:**
1. Agent calls `SelectMarketingImage` with `locale` = `en_GB`.
2. Retriever returns a different asset — the one tagged `locale_en_GB` + `campaign_summer_sale`.
3. Copy is also drafted in British English.

**What to say:** "The `TargetLanguage` session variable drives both the language of the copy and the locale of the image. One signal, two coordinated decisions."

## Optional: live Contentful publish

If you want to show the sync loop live:

1. Have Contentful open on a draft asset tagged `campaign_summer_sale` + `locale_en_US` + `visualStyle_editorial`.
2. Publish it in front of the audience.
3. Rerun Prompt 1. The new asset wins the retrieval (or at least becomes a candidate — depends on your catalog size).

Only do this if you've rehearsed it. The Contentful webhook typically fires within seconds but can occasionally lag, and watching a demo wait is painful.

## If something goes wrong

- **Retriever returns empty:** rerun the prompt with explicit campaign/style terms. The semantic index does better with specific nouns.
- **Image doesn't render:** check [docs/troubleshooting.md](troubleshooting.md) — likely a Contentful URL protocol issue (`//` vs `https://`).
- **Agent doesn't call `SelectMarketingImage`:** the reasoning instructions in Agent Builder haven't been saved. See `docs/agent-build-runbook.md` steps 5–6.
- **Fallback script:** show one hardcoded prompt + screenshot of the DMO rows. The architecture story holds even if the live agent misbehaves.
